# PPB · 포챔스 파티 빌더

Pokémon Champions 싱글 파티를 편집하고 6→3 선출·타입·역할·6단계 구축 규칙을 비교하는 한국어 웹 앱.

**개발 중인 데이터 검증형 프로토타입입니다. 전체 요구사항 완료본이 아닙니다.** 338개 관측 폼과 7종 상세 통계만 반영했습니다. 전체 도감·공식 합법성 대조, 모든 배치, 공개 파티 비교, 정밀 대미지 및 실제 AI 연결은 미완료입니다.

## 기능

- 메가보만다·메가갑주무사·맘모꾸리를 포함한 6마리 편성.
- 기본·메가·X/Y/Z 검색, 타입 필터, 종별 순위. 일부 한글명 미완성.
- 검증된 7종의 기술·특성·물건·성격·배분 편집. 기본값과 사용자 변경 비교.
- 종 중복·고정 슬롯 보호, 자동 저장·되돌리기·예시 복원.
- 메가 최대 1마리 선출 정책, 6→3 조합·구조 순위.
- 실제 기술에 따른 공격 타입, 특성에 따른 방어 무효, 물리/특수 역할 재평가.
- 6단계 구축 설명과 직전 변경 비교, 제한된 샘플 풀의 보완 후보.
- 서버 측 Responses API 어댑터, 미설정·실패 안내, 오래된 총평 표시.
- 모바일 카드·편집 시트와 키보드 사용 가능한 UI.

## 실행

Node.js 22.13 이상, pnpm 사용.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

React 19 / TypeScript / Vinext(Vite) / Cloudflare Worker. `sites()` 빌드 플러그인을 유지합니다.

## 테스트

```sh
node scripts/test.mjs
pnpm exec tsc --noEmit
pnpm build
```

Node 내장 테스트 러너를 사용합니다. TypeScript 순수 계산 모듈은 테스트 시 임시 `.test-build`로 변환됩니다. 상세 결과는 [테스트 보고서](docs/TEST_REPORT.md).

## AI 설정

`.env.example`의 `OPENAI_API_KEY`, `OPENAI_MODEL`을 서버 환경에만 설정하세요. 키를 코드·브라우저·GitHub에 넣지 마세요. 개발 환경에서는 Wrangler 서버 비밀 환경 설정을 사용하고, Sites에서는 소유자 승인 후 비밀 환경변수로 저장해야 합니다.

실제 AI를 활성화하려면 OpenAI Developers 연결 및 비용/키 승인이 필요합니다. 미설정 상태는 HTTP 503을 반환하며 가짜 총평은 생성하지 않습니다. 서버에서 현재 파티를 검증하고 분석을 다시 계산한 뒤 전송합니다. 실패 응답에 키를 포함하지 않습니다. 출력은 텍스트로만 표시합니다.

[OpenAI 공식 텍스트 생성 문서](https://developers.openai.com/api/docs/guides/text). AI의 사실 오류를 완전히 차단하는 출력 검증은 아직 미구현이며, 입력 제한과 지시만으로 사실성을 보장하지 않습니다.

## 배포와 접근

이 GitHub 저장소는 사용자의 승인에 따라 공개입니다. API 키, 사용자 저장 파티, Sites 접근용 인증 정보는 포함하지 않습니다.

Sites는 별도의 소유자 전용 비공개 배포를 사용합니다. `.openai/hosting.json`은 프로젝트 식별 정보만 포함합니다. Sites의 소스 저장·빌드 아카이브·비공개 배포 흐름을 사용하고, 배포 후 접근 허용 사용자가 소유자 1명인지 확인해야 합니다. GitHub 공개 상태가 Sites 공개 전환 승인을 의미하지 않습니다.

브라우저 저장은 기기 로컬이며 다른 브라우저와 동기화되지 않습니다. 새 배포도 동일한 도메인을 유지하면 저장 파티가 유지됩니다.
